写真

Wikimedia Commons・Wikipedia 日本語版

立ち寄り先のカードの写真は、その場所の Wikipedia 記事の代表画像を Wikipedia の API から読み込んで表示しています。 写真は旅さきのものではありません。著作権は撮影者にあり、多くは CC BY-SA などのライセンスで公開されています。

撮影者とライセンスは写真ごとに違います。写真の隅の「写真: Wikimedia Commons」から、 その写真の説明ページ（撮影者・ライセンス・元の画像）を開けます。

観光地・駅のデータ

旅程の候補にする観光地（約5万4千件）と、駅・バス停の位置です。件数は出どころごとのおおよその数です。

国土数値情報「観光資源」（国土交通省）

出典：国土数値情報（観光資源データ）（国土交通省）を加工して作成。約9,500件。

使用許諾条件：非商用（国土数値情報ダウンロードサイト 利用規約）

国土数値情報「文化施設」（国土交通省）

出典：国土数値情報（文化施設データ）（国土交通省）を加工して作成。約3,600件。

使用許諾条件：非商用

国土数値情報「鉄道」「バス停留所」（国土交通省）

出典：国土数値情報（鉄道データ）（国土交通省）・国土数値情報（バス停留所データ）（国土交通省）を加工して作成。 経路が取れない区間の移動時間の目安に、駅（2008年度版）とバス停（2010年度版の一部）の位置を使っています。

使用許諾条件：鉄道は商用可、バス停留所は非商用

Wikipedia 日本語版

各地の一覧記事（温泉地・山・寺院・島・史跡・都道府県の観光地など）から、記事名・座標・冒頭の説明を使っています。約8,900件。 文章の著作権は Wikipedia の各記事の執筆者にあります（執筆者は各記事の履歴にあります）。

ライセンス：CC BY-SA 4.0。 Wikipedia から写した説明文は、同じ CC BY-SA 4.0 のもとで再利用できます。

Wikidata

Wikidata の名前・座標・分類。約14,800件。

ライセンス：CC0 1.0（表示の義務はありませんが、出典として記しています）

OpenStreetMap

© OpenStreetMap contributors。 座標が分からなかった観光地に、名前と都道府県の一致で付けた座標です。約4,200件。

ライセンス：ODbL 1.0。 これらの座標を含む旅さきの観光地データ（kb/）は ODbL の派生データベースにあたり、その部分は ODbL のもとで 公開しています。

Overture Maps

Overture Maps Foundation, overturemaps.org。 座標が分からなかった観光地に付けた座標です。約1,300件。

ライセンス：CDLA Permissive 2.0／Apache License 2.0（1件ずつの出どころによります）

座標つきの観光地一覧

各都道府県の公式観光サイトに挙がっている観光地の名前に、次のサービスで座標を付けた一覧です。約10,600件。 件数は、旅さきに入っている座標がどのサービスから取ったものかの内訳です。

  • Web Services by Yahoo! JAPAN：Yahoo!ローカルサーチ API（店舗・施設の検索。約8,800件）、Yahoo!コンテンツジオコーダ API（寺社・公園・史跡などの地名。約1,100件）
  • 出典：国土地理院（住所検索 API。山・湖・滝・海岸などの地名。約480件）
  • Photon・Nominatim・Overpass API（OpenStreetMap のデータを検索するサービス）。© OpenStreetMap contributors、ODbL 1.0。約230件
  • Wikipedia の記事の座標（CC BY-SA 4.0）・Wikidata（CC0）による検索
川の防災情報 ダムデータ（国土交通省）

出典：川の防災情報（国土交通省）のダムの名前・位置・型式・管理者を加工して作成。約770件。

各都道府県の公式観光サイト

観光地の名前の一覧を「観光地として挙がっているか」の確認にだけ使っています。名前・座標・説明は写していません。

旅さきの収録データ

主な観光地のエリア分けや紹介文の一部は、旅さきで用意したものです。

経路・天気・AI

経路・所要時間（徒歩・車）

Google Maps Platform（Routes API）。© Google。 Google Maps Platform 利用規約に沿って使っています。

電車・バスの乗り換え

Yahoo!路線情報（LINEヤフー株式会社）の検索結果を、旅さきの中継サーバーを通して使っています。

天気

Weather data by Open-Meteo.com（予報と過去の天気）。 ライセンス：CC BY 4.0

AI（希望の読み取り・行き先の選定）

Google の Gemini API で、Gemma などのモデルを使っています （Gemma 利用規約）。AI の答えは間違うことがあります。

外部へのリンク

Google マップなどへのリンクは、各サービスのページを開くだけで、その内容を旅さきに取り込んではいません。

このアプリ自体

プログラム

旅さきのプログラム（HTML・CSS・JavaScript）は The Unlicense でパブリックドメインにしています （ソースコード）。 観光地のデータ（kb/）は対象外で、上に書いたそれぞれのライセンスに従います。

アイコン・字体

画面の記号とアプリのアイコンは、旅さきで描いたものです。字体は端末に入っているものだけを使い、Web フォントは読み込んでいません。
